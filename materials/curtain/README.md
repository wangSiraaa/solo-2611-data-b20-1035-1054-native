# 幕布巡演小例（测色台、参照瓶、排幕与装车单）

`inventory.json`：参照瓶 REF 共 2 份，种类 R 的 L=2，10 日入库，印刷期 20。
方法 M/v1 需 R=1。

`operations_real.json`（真实时间线）：ref-run-1 于 12 日开封并消耗 1 份，
ref-run-2 于 13 日再消耗 1 份，REF 共消耗 2 份，可登记两条参照。

`operations_expired.json`（失效变体）：ref-run-2 推迟到 14 日才开始，
开封 12 + L2 = 14，边界当日不可用，开始失败并释放；REF 只消耗 1 份，
第二条参照（乙台读数）因领用未成功而不能登记。

`curtain.json`：2 台（甲 [0,0]、乙 [0,3]）、26 条布边读数、12 幅布
（7 幅旧、5 幅备 S0–S4，均不可转向）、4 场演出：

- `ex`（容差 1）与 `ex0`（容差 0）共用旧幅 O1、O2，对应题中三个小例；
- `T1`（3 个位置，容差 0）与 `T2`（2 个位置，容差 0）是巡演两站，
  主排法都要用同一件实物 S1，用来演示两团争同一幅；
- eD1/eD2 是同台乙的两条探针边，用来演示共同仪表偏差不能各自算区间再相减。

规模在题定上限内：≤6 台、≤9 个位置、≤12 幅备布。
